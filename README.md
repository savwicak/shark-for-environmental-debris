## About
We have two microcontrollers, one to detect objects from the camera and send signals to the second microcontroller, and the other to receive signals and operate the servo (mouth opener).
This code is for receiving signals from the camera and running the motor.

### For camera detection, we use the K120 camera's built-in module

## Open to see the code project

* open [https://makecode.microbit.org/](https://makecode.microbit.org/)
* click on **Import** then click on **Import URL**
* paste **https://github.com/savwicak/shark-for-environmental-debris** and click import
